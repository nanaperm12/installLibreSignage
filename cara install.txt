
COMMAND LINE TUTORIAL MEMBUAT DISPLAY INFORMASI DIGITAL MENGGUNAKAN STB
 
#1 FLASH ARMBIAN
================
 
*untuk STB HG680-P:
 su  
 reboot update  
 
*untuk STB B680H:
 su
 cd /storage/Download   <== ini adalah lokasi file uboot.bin
                            sesuaikan dengan punya kalian.
 
 dd if=uboot.bin of=/device/block/bootloader
 reboot update
 
 
#2 INSTALL WEB SERVER DISPLAY INFO DIGITAL
==========================================
 
*Flash armbian ke memori internal STB:
 cd
 ./install.sh
 reboot
 
*Setting zona waktu armbian:
 sudo timedatectl set-timezone Asia/Makassar   <== Asia/Makassar adalah zona waktu Indonesia Tengah
                                                   sesuaikan dengan punya kalian.
 timedatectl
 
*Install dan build webserver:
 sudo apt update && sudo apt install -y git apache2 php php-gd pandoc composer make librsvg2-bin
 curl -fsSL https://deb.nodesource.com/setup_16.x | bash -
 apt-get install -y nodejs
 sudo apt install -y ffmpeg
 sudo apt install -y php-xml
 sudo apt install -y doxygen
 git clone https://github.com/eerotal/LibreSignage.git
 cd LibreSignage
 make configure TARGET=apache2-debian-interactive   <== perintah mengkonfigurasi webserver,
                                                        penjelasannya di video tutorial.
 make -j$(nproc)
 sudo make install
 sudo a2dissite 000-default.conf
 reboot
